# 1. Що таке змінна?

У Python змінна — це **ім'я, яке посилається на об'єкт у пам'яті**.

```python
age = 42
```

Не можна думати про змінну як про "коробку". Більш точна модель:

```text
age
 │
 ▼
42
```

---

# 2. Основні типи даних

```python
age = 42          # int
height = 180.5    # float
name = "Ivan"     # str
is_doctor = True  # bool
```

Перевірка типу:

```python
print(type(age))
print(type(name))
```

Результат:

```python
<class 'int'>
<class 'str'>
```

---

# 3. Динамічна типізація

Python дозволяє змінювати тип змінної.

```python
x = 10
print(type(x))

x = "hello"
print(type(x))
```

Результат:

```python
<class 'int'>
<class 'str'>
```

---

# 4. `id()` — адреса об'єкта

```python
a = 100
b = a

print(id(a))
print(id(b))
```

На більшості інтерпретаторів адреси будуть однаковими.

---

Потім:

```python
b = 200

print(id(a))
print(id(b))
```

Тепер адреси різні.

---

# 5. Присвоювання

```python
a = 5
b = a
```

```text
a ─┐
   ▼
   5
   ▲
b ─┘
```

Після

```python
b = 10
```

```text
a ──► 5

b ──► 10
```

# 6. Immutable

Незмінні типи:

* int
* float
* bool
* str
* tuple
* frozenset

```python
x = "Hello"

x += " World"
```

Створюється **новий об'єкт**, а не змінюється старий.

---

# 7. Mutable

Змінні типи:

* list
* dict
* set

```python
numbers = [1, 2, 3]

numbers.append(4)
```

Об'єкт залишається тим самим.

---

# 8. Перетворення типів

```python
age = int("42")
height = float("180.5")
name = str(100)
```

---

Типова помилка:

```python
age = input("Age: ")

print(age + 1)
```

Отримаємо:

```text
TypeError
```

Правильно:

```python
age = int(input("Age: "))

print(age + 1)
```

# 9. `==` та `is`

Це одна з найважливіших тем.

```python
a = [1, 2]
b = [1, 2]
```

```python
a == b
```

Результат:

```python
True
```

Бо значення однакові.

---

Але

```python
a is b
```

```python
False
```

Бо це **різні об'єкти**.

---

Інший приклад

```python
a = None

if a is None:
    print("Empty")
```

Саме так рекомендує PEP 8.

Не так:

```python
if a == None:
```
