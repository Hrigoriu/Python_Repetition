# 8. 🔍 Code Review

Для кожного дня я аналізую:

### Correctness

Чи правильно працює код.

### Python knowledge

Чи правильно використані конструкції Python.

### Code quality

Читабельність, структура, naming.

### DRY

Чи немає зайвого дублювання.

### KISS

Чи рішення не складніше, ніж потрібно.

### YAGNI

Чи немає непотрібної складності.

### Type hints

Наскільки добре ти використовуєш типізацію.

### Architecture

Особливо на пізніших днях — чи правильно розділені responsibility.

---

Оцінювання не обмежується питанням «працює / не працює». Я дивлюся на:

- Correctness — чи правильний результат.

- Python knowledge — наскільки правильно використані конструкції мови.

- Code quality — імена, читабельність, структура.

- DRY — чи не повторюється логіка без потреби.

- KISS — чи рішення не стало складнішим за саму задачу.

- YAGNI — чи немає функціональності, яка не потрібна.

- Type hints — наскільки доречно використана типізація.

- Architecture — особливо на пізніших етапах, коли з'являється поділ відповідальностей.
