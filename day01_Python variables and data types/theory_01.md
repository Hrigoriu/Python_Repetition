# 1. Що таке Python?

Python — це **високорівнева, інтерпретована, універсальна мова програмування**, створена для швидкої та зрозумілої розробки.

* Computer Vision
* Data Science
* Web
* Automation
* кібербезпеці
* медицині
* робототехніці

Саме тому Python є основною мовою для більшості AI Engineer.

# 2. Як працює Python?

Схема:

```text
Код (.py)
      │
      ▼
Python Interpreter
      │
      ▼
Bytecode
      │
      ▼
Python Virtual Machine
      │
      ▼
Результат
```

На відміну від C++, Python **не компілюється одразу в машинний код**. Інтерпретатор читає програму та виконує її.

# 6. Функція `print()`

Виводить інформацію на екран.

Приклад:

```python
print("Привіт")
print(25)
print(3.14)
print(True)
```

Результат:

```text
Привіт
25
3.14
True
```

---

### Вивід кількох значень

```python
name = "Hrigoriu"
age = 42

print(name, age)
```

Результат:

```text
Hrigoriu 42
```

---

### Форматований вивід (f-string)

```python
name = "Hrigoriu"
age = 42

print(f"Мене звати {name}. Мені {age} років.")
```

# 7. Функція `input()`

Використовується для введення даних користувачем.

```python
name = input("Ваше ім'я: ")

print(name)
```

---

Ще приклад:

```python
city = input("Ваше місто: ")

print(f"Ви живете у місті {city}.")
```

---

# Важливо

`input()` **завжди повертає рядок (`str`)**.

Навіть якщо користувач вводить:

```
25
```

Python отримує:

```python
"25"
```

Тому для чисел потрібне перетворення:

```python
age = int(input("Вік: "))
```

# 9. Стиль коду (PEP 8)

Правильно:

```python
patient_name = "Ivan"
```

Неправильно:

```python
PatientName = "Ivan"
```

або

```python
patientname = "Ivan"
```

Для змінних використовують **snake_case**.
